# Relay Garden browser demonstration

Self-initiated work for Héctor R. Sepúlveda A., developed with generative-AI assistance for code, text and vector graphics. This is a free playable demonstration, not a claim of client work, commercial success, exclusive technology or guaranteed accessibility.

The public runtime is visible because the game runs in the browser. Public display does not itself grant commercial adaptation or standalone redistribution rights beyond applicable platform terms and law. A separately packaged source kit adds a configuration studio, tests, documentation and a commercial adaptation license. It is sold through the linked Contra product page. The public demo includes a link to that product; the purchased ZIP does not include this promotional section.

Progress and preferences are stored locally. The game does not transmit that saved progress, but the host receives ordinary page requests.
